# UPSTREAM GRIEVANCES

These reports and proposed fixes helped motivate COSMIC CE. Statuses reflect the public GitHub records checked on November 25, 2026. Test results are attributed to the people who ran them.

On October 1, 2026, upstream announced that it would no longer accept LLM-generated code, comments, or descriptions. The Pop!_OS contributor guide applies that rule to both issues and pull requests. [Policy announcement](https://github.com/pop-os/cosmic-epoch/discussions/3774) · [Pop!_OS contributor guide](https://github.com/pop-os/pop/blob/master/CONTRIBUTING.md#ai-contributions)

| User impact | Upstream reports and patches | What happened upstream |
| --- | --- | --- |
| Turning off a monitor or reconnecting a dock can end the entire desktop session. | [cosmic-comp issue #2727](https://github.com/pop-os/cosmic-comp/issues/2727) · [PR #2839](https://github.com/pop-os/cosmic-comp/pull/2839) · [PR #2784](https://github.com/pop-os/cosmic-comp/pull/2784) | A user reported 15 days and 16 boots without a compositor panic after installing #2839. A maintainer [closed it under the LLM policy](https://github.com/pop-os/cosmic-comp/pull/2839#issuecomment-5928814235) on October 1 and [asked for a handwritten PR and more debugging](https://github.com/pop-os/cosmic-comp/pull/2839#issuecomment-5929582352). The issue is open. The narrower #2784 has been open since August 26 without public comments or review. |
| COSMIC Files can take minutes to open when a mounted network share is unavailable. Users also reported freezes when deleting files. | [cosmic-files issue #1314](https://github.com/pop-os/cosmic-files/issues/1314) · [PR #1741](https://github.com/pop-os/cosmic-files/pull/1741) · [PR #1879](https://github.com/pop-os/cosmic-files/pull/1879) | The author of #1741 reported startup going from 2 minutes 35 seconds to under a second on their machine. It received technical review. The author of #1879 separately reported that startup and deletion freezes stopped on their setup. Maintainers closed both under the LLM policy on September 30. The issue is open. |
| COSMIC Files can fail to connect to a new SFTP server when its host key has never been accepted. | [cosmic-files issue #580](https://github.com/pop-os/cosmic-files/issues/580) · [PR #2015](https://github.com/pop-os/cosmic-files/pull/2015) | A maintainer filed the bug in October 2024 and reproduced it across several versions. The patch author reported successfully opening the remote directory in a test with a fresh host key. A maintainer [closed the PR under the LLM policy](https://github.com/pop-os/cosmic-files/pull/2015#issuecomment-5917882514) on September 30. The issue is open. |
| Large images look blurry at 100% zoom in COSMIC Viewer. | [cosmic-viewer issue #91](https://github.com/pop-os/cosmic-viewer/issues/91) · [PR #111](https://github.com/pop-os/cosmic-viewer/pull/111) | A contributor traced the blur to a 2048 px texture cap and reported a sharper image after raising it. The contributor [withdrew their own PR because of its AI use](https://github.com/pop-os/cosmic-viewer/issues/91#issuecomment-6705617977). The October 5 report is open and has no public maintainer reply. |
| Print Screen or starting a screen share can hard-freeze the desktop session on a Radeon RX 9070 XT. | [cosmic-comp issue #2837](https://github.com/pop-os/cosmic-comp/issues/2837) | The September 9 report includes reproduction steps and a backtrace. Another user said the problem persisted after updating. The issue remains open without a public maintainer reply. |
| The desktop can freeze during ordinary window or file operations. | [cosmic-epoch issue #3744](https://github.com/pop-os/cosmic-epoch/issues/3744) | The report has been open since July 24. Other users posted similar symptoms or logs. No maintainer has replied publicly in the thread. |
| With focus follows cursor enabled, switching workspaces can leave keyboard input going to the wrong window. | [cosmic-epoch issue #3650](https://github.com/pop-os/cosmic-epoch/issues/3650) · [cosmic-comp PR #2737](https://github.com/pop-os/cosmic-comp/pull/2737) | The author reported using the fix daily on a ThinkPad. A maintainer [closed the PR under the LLM policy](https://github.com/pop-os/cosmic-comp/pull/2737#issuecomment-5928936135) on October 1. Another user said the bug had bothered them for at least a year and offered to rewrite the patch. The issue is open. |
| The screen magnifier ignores the configured zoom step when using the mouse wheel. | [cosmic-comp issue #2764](https://github.com/pop-os/cosmic-comp/issues/2764) · [PR #2634](https://github.com/pop-os/cosmic-comp/pull/2634) · [PR #3042](https://github.com/pop-os/cosmic-comp/pull/3042) | Another user built #2634 and found it made mouse-wheel zoom usable without increasing normal scroll speed. A maintainer [closed the PR under the LLM policy](https://github.com/pop-os/cosmic-comp/pull/2634#issuecomment-5928968858) on October 1. A revised submission received two approvals on November 24 and is still open. |
| Closing windows or repeatedly opening the workspace overview can increase VRAM use. | [cosmic-comp issue #2084](https://github.com/pop-os/cosmic-comp/issues/2084) · [PR #2095](https://github.com/pop-os/cosmic-comp/pull/2095) | The patch author measured roughly 200 MiB of accumulated VRAM per test round before the patch on an RTX 2070 and reported that it stopped accumulating with the patch. After technical discussion, a maintainer [closed the PR under the LLM policy](https://github.com/pop-os/cosmic-comp/pull/2095#issuecomment-5929386375) on October 1. The issue is open. |
| Switching keyboard layouts shifts nearby panel items. | [cosmic-applets PR #1458](https://github.com/pop-os/cosmic-applets/pull/1458) | The PR opened July 2 and received two approvals July 21. QA later [showed that the proposed fixed width clipped the longer US (Dvorak) label](https://github.com/pop-os/cosmic-applets/pull/1458#pullrequestreview-5147254372). The PR is open, with the last public activity on September 25. |
| Hovering over a minimized window icon can leave its tooltip stuck on the panel. | [cosmic-panel issue #458](https://github.com/pop-os/cosmic-panel/issues/458) · [cosmic-applets PR #1324](https://github.com/pop-os/cosmic-applets/pull/1324) | The proposed fix has been open since February 21 without public comments or review. |
